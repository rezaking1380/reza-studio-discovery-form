# Reza Studio — فرم نیازسنجی طراحی سایت

فرم آنلاین نیازسنجی مشتریان طراحی سایت برای **Reza Studio**: یک فایل استاتیک (`index.html`)، فارسی و راست‌چین، در ۷ مرحله.

- مشتری فرم را پر می‌کند و در پایان با دکمه «ارسال فرم برای Reza Studio» همه اطلاعات (تک‌تک فیلدها + خلاصه کامل فرم) مستقیم به ایمیل Reza Studio ارسال می‌شود (از طریق FormSubmit).
- دکمه‌های کپی و دانلود خلاصه هم به‌عنوان مسیر پشتیبان در صفحه پایان وجود دارد.
- پاسخ‌های نیمه‌کاره فقط در مرورگر خود مشتری (localStorage) ذخیره می‌شود؛ هیچ داده‌ای روی سرور ذخیره نمی‌شود.

دیپلوی: Vercel (پروژه متصل به همین ریپو — هر push روی `main` به‌صورت خودکار دیپلوی می‌شود).
